```

先读取 docs/04-代码规范.md、docs/00-GitHub协作与整合约定.md、docs/NEXUS-立项与三人推进计划.md，理解代码规范、整体架构、目录边界和整合点。你生成的所有代码必须严格遵守 docs/04-代码规范.md。严格遵守：你独占 nexus-backend/（除 com.nexus.ai 包）、docker/、docs/database-design.md、docs/api-specification.md；不要修改 nexus-frontend/ 和 com.nexus.ai 包内的实现。

【本轮任务：阶段一 工程初始化 + 云资源就绪】
1. 在 nexus-backend/ 创建 Spring Boot 工程（Java 21），建立统一响应格式 Result<T>、全局异常处理、基础配置分层。

3. 定义统一 API 契约，输出 docs/api-specification.md：请求参数、响应结构、权限要求、错误码。至少要覆盖：认证、文件上传、世界模型 CRUD、风险列表、决策/任务、Agent 执行记录。这份契约是成员 C 前端 Mock 开发的依据，务必字段明确。
4. 建立用户认证模块（注册/登录/JWT/退出），验证 user_id 数据隔离。
5. 创建 com.nexus.ai 包骨架与 AI Provider 接口定义（只写接口签名，不写实现，实现由成员 B 完成）。

【完成标准】
```
