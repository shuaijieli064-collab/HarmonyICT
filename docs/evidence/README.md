# NEXUS · 证据目录（docs/evidence/）

> 本目录存放竞赛答辩所需的**可核验留痕**：华为云控制台截图、CodeArts 操作录屏、部署与公网验收证据、Demo 过程截图。
> 由前端与交付物线（对话 C）独占维护；云部署线把截图/录屏文件放进本目录，命名按本文规范执行。

---

## 1. 目录结构

```
docs/evidence/
├── README.md              # 本规范
├── cloud/                 # 云资源与部署证据（云线产出）
│   ├── rds/               # RDS for PostgreSQL 开通与连通
│   ├── redis/             # Redis 开通与连通
│   ├── obs/               # OBS 桶创建与文件上传
│   ├── maas/              # MaaS 模型调用与 OCR 调用
│   ├── codearts/          # CodeArts 代码智能体 + 流水线构建/部署
│   └── deploy/            # ECS 部署、公网健康与验收
├── demo/                  # Demo 演示过程截图与录屏（前端线产出）
└── weekly/                # 每周进度截图（可选）
```

---

## 2. 命名规范

**通用格式**：`<日期>-<阶段>-<对象>-<动作>.<扩展名>`

| 字段 | 取值 | 示例 |
|---|---|---|
| 日期 | `YYYYMMDD` | `20261125` |
| 阶段 | `v1` / `v2` / `v3` | `v2` |
| 对象 | 产品/页面/功能短名（小写连字符） | `rds`、`entity-graph`、`agent-auth` |
| 动作 | `开通`、`连通`、`调用`、`构建`、`部署`、`验收`、`截图`、`录屏` | `连通` |

**示例**

```
cloud/rds/20261125-v2-rds-开通.png
cloud/maas/20261125-v2-maas-调用.png
cloud/deploy/20261126-v2-health-验收.png
demo/20261126-v2-upload-截图.png
demo/20261126-v2-agent-auth-录屏.mp4
```

**规则**

1. 文件名只用 ASCII 连字符 `-` 分隔，不用空格、中文标点或下划线混用（动作字段的中文动词除外）。
2. 同一对象多次留痕时，在动作后追加序号 `-01`、`-02`。
3. 录屏保留原始格式（mp4/webm），不转码压缩，答辩前另存演示版。
4. 截图保留原始分辨率，关键区域可用系统标注工具加框，但不得裁剪掉产品标识/URL/时间戳。

## 3. 证据与文档索引

每个证据文件在答辩材料中引用时，使用相对路径 `docs/evidence/<子目录>/<文件名>`，例如：

> RDS 开通证据见 `docs/evidence/cloud/rds/20261125-v2-rds-开通.png`。

云线在 `README.md` 的「华为云产品使用清单」中引用证据；前端线在演示脚本中引用 Demo 截图。

---

## 4. 提交约定

- 证据文件随对应线的 commit 一起提交，不集中在汇合阶段补交。
- 单个录屏超过 50MB 时，先与主控确认是否改为外链存放，并在本目录留一份 `.md` 说明链接与校验值。
- 凭据、token、带真实个人信息的截图**禁止**进入本目录（红线：凭据不进仓库）。
