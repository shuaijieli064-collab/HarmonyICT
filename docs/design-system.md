# NEXUS · 设计系统（Design System）

> 作者：成员C（前端与产品）。全站统一的「个人智能驾驶舱」视觉风格：**深色科技感**。
> 所有页面与组件必须遵循本规范；规范未覆盖处参考 shadcn 风格惯例并保持一致。

---

## 1. 设计理念

- **驾驶舱隐喻**：信息密度适中、层级清晰，一屏看清「状态 → 风险 → 行动」。
- **深色科技感**：深蓝黑背景 + 青蓝主色 + 紫色点缀，卡片式布局，微弱发光强调重点。
- **一致性**：同类信息在所有页面使用相同的颜色语义、圆角、间距与图表配色。

## 2. 配色（Color Tokens）

### 2.1 背景与表面

| Token | 值 | 用途 |
| --- | --- | --- |
| `bg/base` | `#0B0F1A` | 页面最底层背景 |
| `bg/card` | `#111827` | 卡片、面板背景 |
| `bg/card-hover` | `#1A2233` | 卡片悬浮态 |
| `bg/overlay` | `rgba(11, 15, 26, 0.8)` | 弹窗遮罩 |

### 2.2 主色与强调色

| Token | 值 | 用途 |
| --- | --- | --- |
| `primary` | `#22D3EE`（青蓝） | 主操作按钮、当前态、关键数据 |
| `primary-dark` | `#0891B2` | 主色悬浮态 |
| `accent` | `#A78BFA`（紫） | 图表次要系列、装饰点缀 |
| `success` | `#34D399` | 正常、完成、低风险 |
| `warning` | `#FBBF24` | 关注、进行中、中风险 |
| `danger` | `#F87171` | 异常、失败、高风险 |

### 2.3 文本

| Token | 值 | 用途 |
| --- | --- | --- |
| `text/primary` | `#F1F5F9` | 标题、核心数字 |
| `text/secondary` | `#94A3B8` | 正文、说明 |
| `text/muted` | `#475569` | 占位、禁用 |

### 2.4 风险等级语义（全站统一）

| 等级 | 颜色 | 标签文案 |
| --- | --- | --- |
| 高 | `danger` | 高风险 |
| 中 | `warning` | 需关注 |
| 低 | `success` | 正常 |

## 3. 字体（Typography）

| 层级 | 规格 | 用途 |
| --- | --- | --- |
| 页面标题 | 20px / 600 / `text-primary` | 页面顶部标题 |
| 卡片标题 | 16px / 600 / `text-primary` | 卡片标题 |
| 正文 | 14px / 400 / `text-secondary` | 列表、说明文字 |
| 大数字 | 28px / 700 / tabular-nums | 驾驶舱指标 |
| 辅助 | 12px / 400 / `text-muted` | 时间戳、来源标注 |

字体族：系统默认无衬线栈（Geist Sans 回退到 system-ui），代码/数据用 Geist Mono。

## 4. 间距与圆角

- 间距基准 4px：常用 `8 / 12 / 16 / 24 / 32`（Tailwind `p-2/3/4/6/8`）。
- 页面容器：最大宽 `1280px`，水平居中，移动端留 `16px` 边距。
- 卡片内边距：`16px`（移动端 `12px`）；卡片间间距 `16px`。
- 圆角：卡片 `rounded-xl`（12px）、按钮/输入框 `rounded-lg`（8px）、徽章 `rounded-full`。

## 5. 组件规范

### 5.1 卡片（Card）

- 背景 `bg-card`，圆角 `rounded-xl`，边框 `1px solid rgba(148,163,184,0.1)`。
- 悬浮态：背景 `bg-card-hover` + 微弱外发光（`shadow: 0 0 20px rgba(34,211,238,0.08)`）。

### 5.2 按钮（Button）

| 类型 | 样式 |
| --- | --- |
| 主按钮 | 背景 `primary`、文字 `#0B0F1A`、600 字重 |
| 次按钮 | 透明背景、`1px` 边框 `rgba(34,211,238,0.4)`、文字 `primary` |
| 危险按钮 | 背景 `rgba(248,113,113,0.15)`、文字 `danger` |

- 尺寸：高 36px（默认）/ 44px（移动端主操作）；水平内边距 16px。
- 授权类操作（Agent L2）必须用带确认弹窗的危险/主按钮，不允许静默触发。

### 5.3 徽章（Badge）

- 圆角 `rounded-full`，内边距 `2px 10px`，12px 字号。
- 风险/状态徽章使用 2.4 节语义色，背景为对应色 15% 透明度。

### 5.4 时间线（Timeline）

- 左侧竖线 `1px`（`text-muted` 色），节点圆点 8px，事件类型决定圆点颜色。
- 每条：标题（14px/600）+ 描述（12px/secondary）+ 时间戳（12px/muted）。

### 5.5 图表（ECharts）

- 统一配色顺序：`['#22D3EE', '#A78BFA', '#34D399', '#FBBF24', '#F87171']`。
- 背景透明，坐标轴文字 `#94A3B8`，分割线 `rgba(148,163,184,0.15)`。
- 图谱：实体类型→颜色映射在 `lib/constants.ts` 集中定义，全站一致。

## 6. 动效（Framer Motion）

- 仅用于：页面进入（fade + 8px 上移，250ms）、列表项依次进入（stagger 40ms）、
  卡片悬浮缩放（1.02）、上传进度反馈。
- 禁止大面积持续动画；`prefers-reduced-motion` 用户禁用动效。

## 7. 布局与响应式

- 全局布局：左侧导航栏（桌面 ≥1024px 常驻，宽 240px）；移动端顶部标题栏 + 底部/汉堡导航。
- 栅格：Dashboard 用 12 列栅格；桌面 3 列、平板 2 列、移动端单列堆叠。
- 断点：遵循 Tailwind 默认（`sm 640 / md 768 / lg 1024 / xl 1280`）。
- 交互目标：最小点击区域 44×44px（移动端触控）。

## 8. 命名与文件约定

- 组件文件小驼峰：`risk-card.tsx`；组件名大驼峰：`RiskCard`。
- 设计 Token 落地位置：`app/globals.css`（Tailwind 主题变量）+ `lib/constants.ts`。
- Mock 数据统一放 `mock/` 目录，文件头注明「Mock 数据，联调时替换」。
