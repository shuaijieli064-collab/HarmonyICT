## 本轮任务：阶段一 —— 工程初始化 + 设计系统 + Dashboard 框架

1. 在 `nexus-frontend/` 创建 Next.js 工程（TypeScript），配置 Tailwind CSS、Framer Motion、ECharts。
2. 建立设计规范 `docs/design-system.md`：配色、字体、间距、组件规范，形成统一的个人智能驾驶舱视觉风格（深色科技感或浅色专业感任选其一，全站一致）。
3. 实现 Dashboard（个人智能驾驶舱）页面框架：当前状态、目标进度、近期事件时间线、风险摘要、Agent 任务、今日行动。先用 Mock 数据填充，布局须在桌面与移动端自适应。
4. 实现基础路由与全局布局：Dashboard / World Model / Intelligence Center / Decision Lab / Agent Center / Asset Center 六个页面骨架。
5. 实现文件上传交互组件（拖拽 + 选择 + 上传进度 + 结果展示），对接契约中的上传接口（未就绪用 Mock）。
