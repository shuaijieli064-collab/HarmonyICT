# NEXUS · 录屏脚本（V3 初稿）

> 用途：竞赛需要的操作证据录屏。录屏依赖云线上线，本脚本先备好，云线提供公网地址后直接按此录制。
> 证据归档命名按 [`evidence/README.md`](evidence/README.md)：`demo/YYYYMMDD-v2-<对象>-录屏.mp4`。

---

## 录屏通用要求

- 分辨率 ≥ 1280×720，帧率 25/30fps，原格式保存（mp4/webm），不转码压缩。
- 录制时**露出浏览器地址栏**（证明是真实 URL）、关键操作停留 2 秒以上。
- 旁白与字幕二选一；关键安全点（二次确认）建议加字幕强调。
- 每段录屏控制在 1–3 分钟，便于答辩插入。
- 红线：录屏画面不得出现明文凭据/token；先用脱敏演示账号。
