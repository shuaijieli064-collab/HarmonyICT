# NEXUS 演示脚本（初稿 · 按立项「演示故事」逐页走查）

> 版本：v0.1（2026-11-24，随体量扩充第二波更新）　负责人：C 主笔 / A·B 校对
> 演示故事（立项原文）：大学生上传笔记本发票、订阅记录、学习计划 → 系统抽取出设备、购买日期、保修期、预算、目标
> → 展示个人世界模型 → 发现「订阅即将续费」「任务与目标期限冲突」风险 → 授权 Agent 创建待办 → 展示执行结果。
> 演示环境：云上部署后按本脚本顺序走查；每步标注【华为云触点】用于答辩对应评分点。

## 0. 开场（30 秒）

- 一句话定位：**NEXUS 是个人资料智能管家——上传资料，AI 抽取成结构化事实，系统主动发现风险，授权后生成行动。**
- 架构一页：Next.js 前端 + Spring Boot 后端 + RDS PostgreSQL / Redis / OBS / MaaS / OCR（【触点：华为云产品全家桶】）。
- 强调红线：风险结论只由规则产生（rule_code 可追溯），模型只做解释；Agent 权限 L0–L2、不碰支付。

## 1. 登录与数据准备（1 分钟）

| 步骤 | 操作 | 看点 |
| --- | --- | --- |
| 1.1 | 注册/登录演示账号 | JWT 无状态认证；`user_id` 数据隔离 |
| 1.2 | 上传 `nexus-ai/testdata/demo/` 三份资料：`warranty-invoice.pdf`、`budget-subscription.txt`、学习计划图片 | 文件入 OBS【触点：OBS】；PDF 分页渲染 → 华为云 OCR【触点：OCR】；MaaS 结构化抽取【触点：MaaS 大模型】 |
| 1.3 | 指出抽取结果的置信度与来源溯源（sourceId → 原文件） | AI 输出带证据，不凭空捏造 |

## 2. 世界模型页（1.5 分钟）

- 实体关系图谱：**实体-事实主干 + 同源资料边（co_source）+ 事件归属 + 风险关联边**——
  一份发票同时牵出「笔记本」和「订阅」两个实体（演示图谱的关联发现能力）。
- 手动创建一个实体（如「ICT 大赛目标」），展示重名 20104 提示。
- 顶部导出按钮：**导出事实/实体/风险 CSV**，现场打开文件（演示"资料可带走"）。

## 3. 风险发现（1.5 分钟）

- 触发规则（后台 60s 扫描后自动出现，或提前预备好数据）：
  - `SUBSCRIPTION_EXPIRY_7D`：云盘订阅 11-28 自动续费（7 天内）
  - `DEADLINE_1D`：初赛作品提交截止
  - `BUDGET_OVERSPENT`：订阅月度支出占预算 116%
  - （加分项）`DUPLICATE_SUBSCRIPTION` / `SUBSCRIPTION_PRICE_CONFLICT`：说明数据冲突检测
- 打开风险详情：**证据事实列表 + rule_code**，说明"为什么会有这条风险"完全可追溯。

## 4. Agent 执行（2 分钟）

| 步骤 | 操作 | 看点 |
| --- | --- | --- |
| 4.1 | Agent 中心输入「笔记本保修快到期了，提醒我处理」 | 意图解析 → 计划：create_task（L1） |
| 4.2 | 输入「把笔记本的保修到期改成 2027-06-01」 | 计划：update_fact（**L2**），展示授权二次确认弹窗 |
| 4.3 | 点击授权 | 执行器真实落库：事实链式失效 + 新事实；日志留痕（run + action_logs） |
| 4.4 | 输入「2026-11-25 安排小组评审日程」 | create_event（L2）→ 事件时间线新增；白名单外动作（如"转账"）直接拒绝 |

## 5. 通知中心 + 驾驶舱（1 分钟）

- 通知中心：风险产生、Agent 动作完成的站内提醒；未读徽标、全部已读。
- 回到驾驶舱：聚合统计接口实时反映（事实/风险/任务计数、风险等级分布）。
- 世界模型图谱上风险节点高亮（risk_on 边）。

## 6. 周报（1 分钟）

- 近 7/14/30 天切换：新增事实/事件/风险、任务完成率、Agent 执行数。
- 每日活跃度趋势条形图 + 期内代表性风险。
- 导出任务 CSV 备份。

## 7. 收尾（30 秒）

- 情报中心/资产中心一页带过（聚合视图）。
- 回到架构图：「从想法到应用」全流程——CodeArts 全程参与（【触点：CodeArts 录屏佐证】）。

## 风险预案

| 风险 | 应对 |
| --- | --- |
| OCR/MaaS 现场调用慢或失败 | 提前跑好一份已抽取数据；现场上传用 TXT（走 MaaS，不依赖 OCR） |
| 风险规则 60s 扫描等待 | 演示前 5 分钟预热数据；或现场点「重新扫描」（如有手动触发入口） |
| 网络抖动 | 本地 `localhost` 后端 + 云上后端双环境随时切换 |
| 被问"为什么不用模型直接判风险" | 红线话术：可复现、可审计、可测试；模型只在解释层 |
