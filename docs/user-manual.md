# NEXUS · 用户手册（V3 初稿）

> 面向答辩评委与普通用户，说明如何上手使用 NEXUS 完成「资料 → 事实 → 风险 → 行动」全链路。
> 配合 [`demo-script.md`](demo-script.md) 使用：本手册讲「怎么用」，演示脚本讲「怎么讲」。

---

## 1. 这是什么

NEXUS 是个人资料智能管家。你上传发票、订阅、计划等资料，它会：

1. 用 AI 把资料抽成**可溯源的结构化事实**（谁、什么、什么时候、从哪里来）；
2. 组成一张**个人世界模型**图谱，让零散信息连成网络；
3. 用规则主动发现**风险**（如订阅快续费、任务与期限冲突），并给出依据；
4. 在你**显式授权**后，让 Agent 生成待办、更新记录，全过程留痕。

> 边界：风险结论只由规则引擎产生，AI 只做理解与解释；Agent 只能做 L0–L2 的只读/建议/内部操作，**不会支付、不会操作外部账户**。

## 2. 开始使用

### 2.1 环境

- 浏览器：Chrome / Edge / Safari 现代版本，桌面端与移动端均可。
- 本地演示：运行 `scripts/dev-start.sh`（Windows 用 `.bat`），前端 <http://localhost:3000>。
- 公网演示：使用评委提供的云上链接（云线上线后填入 README）。

### 2.2 注册与登录

1. 打开首页 → 未登录时各页面会提示「请先登录」。
2. 进入 `/login`，用邮箱/用户名注册或直接登录。
3. 登录成功后 JWT 保存在浏览器本地，页面显示登录态。

> 数据按用户隔离：你只能看到自己账号下的事实、风险与执行记录。

## 3. 功能使用

### 3.1 上传资料（驾驶舱）

1. 在驾驶舱的上传区拖拽文件，或点击选择文件。
2. 支持 PDF / Word / Excel / TXT / Markdown / 图片（PNG/JPG），单个 ≤ 20MB。
3. 观察两段进度：「上传中」→「AI 抽取中」→「已完成」。
4. 完成后，下方列出抽取出的事实，每条带**置信度**与**可信状态**（已确认/推断/待核实）。

**失败怎么办**
- 不支持的类型/超限/空文件：客户端会立即拦截并说明原因，换合规文件即可。
- 抽取超时：点「重试轮询」复用已上传的 sourceId 继续等待；若后端明确标记失败，请检查文件内容后重新上传。

### 3.2 世界模型

- **图谱**：实体为大节点、事实为小节点，按类型着色；滚轮缩放、拖拽移动，点开事实看取值与置信度。
- **实体/事实列表**：核对最近落库的实体与事实；可手动创建实体（类型 + 名称 + 可选 JSON 属性）。
- 空态提示：先上传资料完成抽取，图谱和列表会自动出现内容。

### 3.3 情报中心（风险）

- 每张风险卡显示**等级徽章**（高风险/需关注/正常）、**触发规则**、触发原因。
- 点「查看风险依据」展开关联事实快照，看到风险是基于哪些事实命中的。
- 可「确认」或「解决」风险，状态会更新。

> 请特别注意：这里展示的规则码与事实依据，就是「风险不是 AI 随口说的」的证据。

### 3.4 决策实验室（只读）

- 引擎族风险分布、未来 30 天时间线、12 个月假设推演沙盘。
- 这部分是**只读展示**，不产生真实风险结论、不执行任何动作。

### 3.5 Agent 中心（授权执行）

1. 在「发起 Agent 执行」输入意图（如"整理本月资产变动"），点「创建」。
2. 在记录列表选中该 run，点「执行编排」触发异步执行。
3. 刷新后查看操作日志；出现 L2 待授权项时，点「授权执行（L2）」。
4. **会弹出二次确认**：明确告知「该操作将真实执行并写入任务/事实」，确认后才会执行；也可取消或拒绝。
5. 授权后，任务列表与执行日志回填；下方「审计时间线」展示授权人、授权时间、授权决定、变更前后值、执行摘要等审计字段。

> 安全设计：授权必须显式二次确认，绝无静默执行；所有 L2 动作都可追溯。

### 3.6 资产中心

- 以表格展示资产类事实，支持窄屏横向滚动查看。

## 4. 主题与移动端

- 顶部导航有主题切换按钮：深色「暗夜玻璃」（默认）/ 浅色白磨砂，切换后记住偏好。
- 移动端（<1024px）使用顶部栏 + 汉堡菜单导航，页面单列堆叠，触摸目标 ≥44px。
- 全站风险色语义统一：高风险红、需关注黄、正常绿。

## 5. 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 页面提示「请先登录」 | 未登录或 JWT 过期 | 前往 `/login` 重新登录 |
| 图谱空白 | 未抽取到实体，或登录态失效 | 先上传资料完成抽取；确认已登录 |
| 上传后长时间「AI 抽取中」 | 后端异步抽取未返回事实 | 点「重试轮询」；超时后到来源列表查状态 |
| 浅色主题下文字偏淡 | 早期版本语义色未适配浅色 | 已修复：浅色主题使用更深的语义色变体 |
| 无风险可看 | 尚无 open 风险 | 上传含期限/订阅类资料，规则引擎命中后会出现 |

---

## 6. 数据与隐私红线

- 凭据只进环境变量与凭据管理，不进仓库、日志、对话。
- 每条事实可定位来源；风险展示触发规则与证据。
- 用户业务数据严格按 `user_id` 隔离，无越权访问。
